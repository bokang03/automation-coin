# aoa-bot: 워뇨띠(aoa) 매매 습관을 옮긴 코인 선물 매매봇

원자료: `aoa_public_2021-12-31_with_letter.zip` (2018-03 ~ 2021-12 BitMEX 체결 144만 건, 지갑 내역, 90일 서한)

> **백테스트상 이 전략은 수익이 나지 않는다.** 아래 "백테스트 결과"를 읽기 전에는 실제 돈을 넣지 말 것.

## 봇

바이낸스 USDT 무기한 선물(BTC)을 1시간봉 기준으로 매매한다. 규칙은 [aoabot/strategy.py](aoabot/strategy.py)에 있고, 각 규칙의 근거가 된 통계는 아래 분석 절에 있다.

| 규칙 | 근거 (워뇨띠 데이터) |
|---|---|
| 변동성 레짐 ≥ 1.6일 때만 진입 | 진입 시점의 변동성이 평소보다 높은 비율이 2배 |
| 직전 4시간 ±3% 이상 움직이면 반대로 진입 | 급락 뒤 롱 57%, 급등 뒤 롱 42% |
| 진입과 동시에 손절(1시간 ATR × 3), 12시간 지나면 정리 | 손실 거래를 평균 43시간 끌었고 그게 가장 큰 손실원 |
| 수익이 ATR만큼 나면 한 번만 추가 진입, 손절가는 본전으로 | 불타기 승률 83%, 물타기 67% |
| 물타기 금지 | 같은 근거 |
| 거래당 자산 1% 위험, 명목가치 ≤ 자산 × 2 | 워뇨띠의 일간 최대 손실 −44%는 따라 하지 않는다 |
| 하루 −3%면 그날 신규 진입 중지, 최고점 대비 −25%면 전부 청산하고 정지 | 계좌 보호 |

```
run_bot.bat                  # 모의매매 (기본값). 실제 시세로 가상 체결, 60초마다 확인
run_bot.bat --once           # 한 번만 확인하고 종료
run_backtest.bat --start 2022-01-01
.venv\Scripts\python -m pytest -q
```

- 기록: `logs/bot.log`, `logs/trades.csv`, 상태는 `state/paper.json` (실매매는 `state/live.json`)
- 디스코드 알림: 환경변수 `AOA_DISCORD_WEBHOOK`에 웹후크 주소를 넣으면 진입·청산·정지 때 알림
- 최대 낙폭 정지가 걸리면 봇이 멈춘다. 원인을 확인한 뒤 state 파일의 `risk.halted`를 `false`로 바꿔야 다시 진입한다.

### 실매매로 바꾸려면

1. `config.yaml`에서 `demo: true`로 두고 바이낸스 **데모 계정** API 키로 먼저 시험한다.
2. 키는 파일이 아니라 환경변수 `AOA_API_KEY`, `AOA_API_SECRET`에 직접 넣는다.
3. `mode: live`로 바꾸고 `run_bot.bat --live`로 실행한다. 둘 중 하나만 있으면 실행을 거부한다.
4. 시작할 때 거래소 포지션과 봇 기록이 다르면 시작하지 않는다. 손절은 거래소에 STOP_MARKET(reduceOnly)으로 걸고, 손절 주문이 실패하면 바로 청산한다.
5. 바이낸스 BTCUSDT 최소 주문 금액(약 100 USDT) 때문에 자산이 수백 USDT 미만이면 진입이 거부될 수 있다.

실매매 경로(`LiveBroker`)는 API 키 없이 만들었기 때문에 **실제 거래소에서 한 번도 돌려보지 않았다.** 데모 계정에서 진입·손절·청산이 모두 되는지 먼저 확인할 것.

### 백테스트 결과

BitMEX 1시간봉, 초기 자산 10,000, 수수료 0.05% + 슬리피지 0.02% (편도).

| 구간 | 전략 | 단순 보유 |
|---|---|---|
| BTC 2018-04 ~ 2021-12 | −6.8%, 샤프 −0.31, 최대낙폭 −14.8%, 196회, 승률 47% | +569%, 최대낙폭 −71% |
| BTC 2022-01 ~ 2026-09 | −9.2%, 샤프 −0.43, 최대낙폭 −11.7%, 132회, 승률 42% | +65%, 최대낙폭 −67% |
| ETH 2018-10 ~ 2021-12 | −23.7%, 샤프 −1.29, 최대낙폭 −24.7% | +1,487% |
| ETH 2022-01 ~ 2026-09 | −4.1%, 샤프 −0.16, 최대낙폭 −9.8% | −34% |

- 손절·위험 관리 덕분에 낙폭은 작지만, 진입 신호 자체에 우위가 없다.
- 손절·불타기를 끄고 1배로만 돌리면 BTC 2022~는 +27%이지만 2018~2021은 −20%(최대 낙폭 정지)로, 기간에 따라 뒤집힌다.
- 파라미터(±3%, 1.6)는 2022~2026 구간을 이미 본 뒤에 고른 값이라 BTC 2022~ 결과조차 낙관적이다. ETH 2022~만 고르기 전에 안 본 구간이다.

## 데이터에서 확인한 사실

- 입금 14.5 BTC → 실현손익 +3,537 BTC, 출금 2,833 BTC. 연도별 실현손익 172 / 516 / 764 / 2,069 BTC.
- 체결 기준 XBTUSD 94만, ETHUSD 33만 건. 나머지 알트코인은 적다.
- 재구성한 포지션이 펀딩 기록 3,961건과 100% 일치한다.
- BTC 증거금 + 인버스 계약 구조라서, 계약상 숏의 상당 부분은 보유 BTC를 헤지하는 포지션이다. 순 달러 노출(1 + 계약 레버리지)로 보면 시간의 68%는 순롱, 14%는 순숏, 18%는 거의 중립이다.

## 매매 스타일 (XBTUSD 라운드트립 2,589건)

| 항목 | 값 |
|---|---|
| 승률 | 78% (롱 80%, 숏 77%) |
| 평균 이익 / 평균 손실 | +0.67% / −0.88% (손익비 0.76) |
| 보유 시간 중앙값 | 26분. 2018년 12분 → 2021년 15시간으로 길어짐 |
| 롱/숏 비중 | 거의 50:50, 매년 일정 |
| 지정가(메이커) 비중 | 체결의 54%, 2021년 진입은 73% |
| 스톱 주문 청산 | 0.6%. 손절 주문을 거의 안 쓰고 손으로 정리 |
| 강제청산 | 2018년 초에 집중, 이후 거의 없음 |

- **변동성이 클 때만 매매한다.** 진입 시점의 변동성 레짐 > 1.5 비율이 26%(평소 12%), 거래량은 평소의 약 1.4배.
- **단기 역추세 성향은 약하게만 있다.** 직전 4시간 급락 후 롱 비중 57%, 급등 후 42%.
- **물타기 거래 성적이 가장 나쁘다.** 불리한 가격에 추가 진입한 829건: 승률 67%, 하위 5% −1.8%. 유리한 가격에 추가(불타기)한 230건: 승률 83%, 평균 +0.9%.
- **손실 거래를 오래 보유한다.** −1% 이상 손실 거래의 평균 보유 43시간, 나머지 11시간.
- **소수 거래가 수익을 좌우한다.** 상위 20건 이익이 전체 순이익의 약 1.5배다(나머지는 합쳐서 손실).

## 봇 가능성 검증

| 전략 | 2018–2020 | 2021 | 2022–2026 |
|---|---|---|---|
| 워뇨띠의 실제 순노출 방향을 1시간 단위로 따라하기 | 샤프 1.69 | 샤프 1.33 | (자료 없음) |
| BTC 단순 보유 | 샤프 0.70 | 샤프 0.54 | 샤프 0.21 |
| 행동 복제 모델 (시장 피처 → 워뇨띠의 방향) | 학습 일치 90% | 일치 64% (최빈값 69%보다 낮음), 샤프 0.35 | — |
| 습관 규칙 (고변동성 + 4시간 역추세), 27개 조합 | 최고 샤프 0.46 | 27개 모두 샤프 > 0 | 21/27 손실, 사전 선택 조합 −35% |

결론: 워뇨띠의 판단은 1시간 단위에서도 보일 만큼 실제 우위가 있지만, 가격·거래량 피처로는 그 판단을 재현할 수 없다. 모델은 기간을 외우고, 규칙은 2021년 이후에 무너진다. 이 자료만으로 수익 나는 봇을 만든다는 근거는 없다.
